V2.18.2 AUDIT NOTES

Root causes addressed from the V2.18.1 run:
1. 4H BTC evidence was bearish (-2.19) while 1H/15m/5m were bullish. The previous scenario could label this as a confirmed upside continuation and globally veto shorts. The new engine makes the 4H conflict explicit and refuses to call the lower-timeframe move an actionable continuation until the higher-timeframe conflict resolves.
2. Historical BTC/ETH unresolved 1H levels populated a hard-block list. Multiple otherwise independent altcoin candidates were rejected solely because BTC was near resistance or ETH had a role-reversal level. The new implementation uses bounded score adjustments; the historical-level function no longer returns hard blocks for these contexts.
3. The cycle summary counted only trades tagged with the exact current strategy version, while outcome notifications could include retained older-version trades. The new summary labels current cohort metrics separately from all retained open/closed counts.
4. The startup line previously hard-coded a 120-day 15m lookback although the source default was 365 days and environment variables could override it. The line now prints the actual runtime constants.

Design boundaries:
- Scenario scores are heuristic evidence scores, not statistical probabilities.
- 4H conflict suppresses a definitive BTC next-move directional veto; it does not suppress independent altcoin analysis.
- A confirmed BTC structural breakdown remains a safety block for LONGs.
- Historical BTC/ETH context is secondary evidence, not a substitute for each altcoin's own structure, flow, entry location, spread and net-RR checks.
- This release does not change entry pattern definitions, SL/TP construction, minimum score, minimum net R:R, or fee assumptions.

Validation performed locally:
- Syntax: node --check.
- Synthetic 4H-opposed reclaim case: passed (neutral/non-actionable).
- Synthetic fully aligned bullish reclaim case: passed (actionable LONG).
- Synthetic unresolved historical resistance case: passed (soft penalty, no hard block).

Not validated:

- Full 179-market scan under GitHub Actions rate limits.
- Forward paper performance or backtested win rate.
